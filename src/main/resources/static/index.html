The Observatory

The sky over Paris, where this app runs. Every star, planet, comet, nebula and constellation on the chart is one document in a MongoDB collection, and each kind of object keeps its own shape.

Ask the sky

Each question runs a real find() on the sky collection.

db.sky.find({})

Pick an example or type a question.

    Periodic comets

    Comets move too fast for a star chart. Their documents hold an orbital period and a last perihelion, so the page can tell when each one comes back.

    Log a discovery

    Each kind of object has its own fields. The server checks them, then inserts a document with exactly that shape.
